# Módulo — Formatação por Canal

A estrutura (esqueleto + devices) é a mesma. O que muda é como o texto se veste em cada canal. Carregue só a seção do canal escolhido.

---

## E-mail

O remetente importa mais que o assunto. Lembre o usuário de mandar sempre do mesmo nome reconhecível (a pessoa/marca, nunca "noreply" nem "Equipe").

**Anatomia:**
1. **Assunto** — até 50 caracteres (corta no mobile). Específico, nunca vago ("Novidades", "Importante" reprovam). Cinco ângulos: pergunta, número, direto com nome, curiosidade, teaser de história.
2. **Preheader** — 90 a 140 caracteres. Completa o assunto, não repete. Segundo gancho.
3. **Corpo** — hook na primeira linha, contexto, valor, parágrafos curtos (1-3 linhas), negrito só no que importa.
4. **CTA** — um principal, específico ("Quero meu acesso", não "clique aqui"). Em e-mail longo, repete no topo e no fim.
5. **P.S.** — uma das partes mais lidas. Use pra reforçar a oferta, adicionar um bônus ou prova.
6. **Assinatura** — humana, primeira pessoa.
7. **Descadastro** — link de descadastro que funciona + endereço (exigência legal de e-mail marketing).

**Spam (atenção no modo Publicitário):** CAPS na frase inteira, "!!!", excesso de emoji e palavras como "GRÁTIS!!!" derrubam a entrega. No e-mail, tempere o Publicitário: no máximo 1-2 emojis, CAPS só em 1 palavra.

**Comprimento por intenção:** transacional/aviso 50-125 palavras, educacional 150-300, com história 300-500.

**Formato de entrega:**
```
Assunto (2 opções): [op1] / [op2]
Preheader: [texto]

[corpo formatado, com quebras de parágrafo]

[CTA] → [LINK]

P.S. [reforço]
— [NOME]
```

## WhatsApp

Disparo pra lista de transmissão. Mobile, leitura rápida, íntimo.

- **Hook em negrito** na primeira linha. No WhatsApp, negrito é `*texto*` (um asterisco de cada lado).
- **Quebras de linha** entre blocos curtos. Nada de parede de texto. Cada ideia respira.
- **Itálico** com `_texto_` pra subtom (legenda, observação).
- **Emoji** funcional (👇 👉 ⏳), com parcimônia. Sóbrio quase não usa; Publicitário usa mais; Próximo usa leve e pessoal.
- **Link** sozinho numa linha, completo. Sem encurtador suspeito.
- **CTA único**, geralmente "preenche o formulário", "entra no grupo", "clica no link".
- **Opt-out:** quando for disparo de lista/Manychat, fechar com uma linha discreta de saída: `Pra parar de receber, responde SAIR.`

**Formato de entrega:** o texto pronto, já com `*negrito*` e quebras, exatamente como vai ser colado.
```
*[Hook em negrito]*

[bloco curto]

[bloco curto]

[CTA]
[LINK]
```

## Stories

Sequência de telas. Cada slide é um cartão de texto. Texto enxuto, uma ideia por bloco.

- **Título (obrigatório em todo slide):** frase conversacional, máximo 6 palavras, soa como alguém começando a falar ("Pra quem não viu...", "O ponto principal é:"). Nunca título jornalístico/descritivo.
- **Blocos:** 2 a 3 por slide, cada um com 27 a 45 palavras. Cada bloco é uma unidade de pensamento que se sustenta sozinha. Não picotar só pra encher cota.
- **CTA:** elemento separado, nunca dentro de um bloco. Vai só no último slide, depois do último bloco. Formato: ação curta + palavra-gatilho ("Responde com MANUAL pra receber").
- **Número de slides:** o usuário define. Se não definir, sugira pelo volume de conteúdo útil.
- **Emoji:** segue o modo. Sóbrio sem; Próximo/Publicitário leve.

**Formato de entrega:**
```
SLIDE 1 / [total]
Título: [título conversacional]
Bloco 1: [27-45 palavras]
Bloco 2: [27-45 palavras]

SLIDE 2 / [total]
Título: [...]
Bloco 1: [...]
...
CTA: [ação + PALAVRA-GATILHO]   (só no último slide)
```

> Para qualquer canal: se um campo depende de dado que o usuário não deu (preço, data, link, número), entregue com placeholder visível e avise numa nota curta no fim.
